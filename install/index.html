Installer les widgets Zeal Motor

Environ 5 minutes sur votre iPhone ou iPad. Aucun compte ni mot de passe à créer.

1Installer Scriptable

Dans l'App Store, installez l'application gratuite Scriptable (Simon B. Støvring), puis ouvrez-la une fois.

Ouvrir l'App Store

2Ajouter les deux scripts

  1. Touchez Copier le script ci-dessous.
  2. Dans Scriptable, touchez +, touchez la zone de texte puis Coller.
  3. Touchez le titre en haut et renommez le script exactement comme indiqué, puis Done.
Zeal Général
Télécharger
Zeal Personnel
Télécharger

3Activer votre appareil

Votre gestionnaire vous montre un QR code sur son écran. Visez-le avec l'appareil photo de votre iPhone, touchez Ouvrir dans Scriptable, puis Activer.

Ce QR code est personnel : il donne accès à vos messages. Ne le photographiez pas et ne le partagez pas.

4Ajouter les widgets

  1. Appuyez longuement sur l'écran d'accueil, puis Modifier › Ajouter un widget.
  2. Choisissez Scriptable, une taille, puis Ajouter le widget.
  3. Appuyez longuement sur le widget › Modifier le widget : Script = Zeal Personnel, When Interacting = Run Script.
  4. Recommencez avec Zeal Général.
Les widgets se mettent à jour quand iOS le décide (en général toutes les 15 à 60 minutes). Touchez un widget pour voir tous vos messages à jour.
